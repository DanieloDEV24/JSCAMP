# JSCAMP - Bootcamp Full Stack

Repositorio con los proyectos y ejercicios realizados durante **JSCAMP**, 
el bootcamp de desarrollo web full stack organizado por [midudev](https://github.com/midudev) 
e InfoJobs.

## 📚 Sobre el bootcamp

JSCAMP es un programa intensivo de formación en desarrollo web moderno, 
centrado en el ecosistema de JavaScript tanto en frontend como en backend, 
con proyectos prácticos y contenido orientado a la empleabilidad real.

## 🛠️ Tecnologías

- HTML5 & CSS3
- JavaScript
- React
- Estado Global & React Router
- Node.js & Express
- Testing
- TypeScript
- Inteligencia Artificial
- SQL
- CI/CD
- Docker
